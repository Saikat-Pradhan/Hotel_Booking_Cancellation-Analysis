# Hotel Booking Cancellation Analysis:-
---------------------------------------

Project Overview:-
This project explores booking behavior and cancellation patterns within hotel data, using Microsoft Excel. 
It highlights how Excel can be used to uncover business risks, seasonal trends, and customer segments most 
likely to cancel—helping hotel teams optimize operations and reduce lost revenue.

Objective:-
- Identify key factors contributing to booking cancellations
- Visualize seasonal and behavioral trends
- Segment guests based on likelihood to cancel
- Empower hotels to take data-driven decisions using Excel alone

Tools & Techniques Used:-
- Excel Functions (IF, COUNTIFS, AVERAGEIFS, VLOOKUP, etc.)
- Pivot Tables & Slicers
- Conditional Formatting for risk highlighting
- Charting (Bar Charts, Histograms, Line Charts)
- Data Cleaning & Preparation
  
Features of the Dashboard:-
- 📆 Cancellation patterns by month and year
- 🧍 Customer segmentation based on lead time, booking type, and room preference
- 🚫 Cancellation rate comparisons across market segments and deposit types
- 🎯 Interactive filtering via slicers and visuals
  
Key Metrics Analyzed:-
- Lead Time — How far in advance the booking was made
- Booking Status — Whether the reservation was canceled or completed
- Arrival Date — Seasonal trends in cancellations
- Deposit Type — Impact of financial commitment on customer retention
- Customer Type — Behavior differences between repeat and new guests
- Special Requests — Influence of guest preferences on cancellations
